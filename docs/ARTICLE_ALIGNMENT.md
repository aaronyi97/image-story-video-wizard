| 只问当前必需的材料或决定 | 每个阶段都有 `Ask now`，限定在当前阶段 | 已对齐 |

## 特意不写死的内容

- 生图和配音的单价会变，Skill 会在实际选择 API 时重新估算，不把某一天的价格写成永久规则。
- 「稳定日更」和「人工介入低于一小时」是目标，必须在多期真实运行后记录，不会因为一期成片就声称已经实现。

## 当前验收边界

- Skill 结构、全部 16 个阶段、五段式交互、关键确认门、状态文件初始化和校验已通过自动测试。
- WorkBuddy/Kimi 和各个外部 API 的实际调用需要当前账号、模型和权限，不在本地结构测试里冒充验收。
